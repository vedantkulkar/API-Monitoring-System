# API Monitoring System

A Java Full Stack project designed to monitor API availability and response times.

## Project Overview

The API Monitoring System helps users monitor APIs and check whether they are available or down. It displays API status and response time through a web-based dashboard.

## Technologies Used

- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Build Tool:** Maven
- **Development Environment:** Spring Tool Suite (STS)

## Features

- Monitor API availability.
- Display API status as UP or DOWN.
- Measure API response time.
- Add APIs for monitoring.
- Edit and delete API entries.
- Search APIs.
- Display dashboard statistics.
